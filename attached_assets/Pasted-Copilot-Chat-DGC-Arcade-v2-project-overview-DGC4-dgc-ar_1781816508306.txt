What this is
DGC Arcade v2 is a crypto-enabled arcade gaming platform (originally launched as v1) now being rebuilt with a modern monorepo architecture. It's a full-stack application where players can deposit crypto, play games (primarily slots), track balances, and request withdrawals — all managed through an owner-only "DG AI" assistant that can execute database queries, deploy code, and reconcile balances.

Stack
Language(s): TypeScript (85.8%), HTML, CSS, JavaScript
Framework / runtime: Node.js (Express backend), React 19 + Vite (frontend)
Notable libraries: Drizzle ORM, React Query, TailwindCSS, Zod (schema validation), Pino (logging), Expo (mobile considerations)

How it fits together:
Players interact with the React frontend (dgc-arcade) which calls the Express API (api-server) at /api. The API validates requests with Zod schemas, queries the Drizzle ORM database (Neon PostgreSQL on production), manages bets and balances, and processes crypto payments via Plisio webhooks. Behind the scenes, an AI assistant (owner-ai.ts) available only to the owner (fanodgc) can execute database mutations, trigger code commits + deployments, and manage the system.
